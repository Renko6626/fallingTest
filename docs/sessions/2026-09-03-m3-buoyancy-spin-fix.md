# 会话：水里的刚体越转越快（M3 浮力修订）

## 现象

用户目检：刚体在水里不稳，"旋转—加速—再旋转，直到旋转超级快"。

## 复现与取证（systematic-debugging）

- 探针：`Sim::body_state` 诊断视图（新增、保留）+ 临时逐 tick 打印（已删）。crate_yard 水塘里
  单放 32×6 木条 35° 入水：|ω| 从 1 单调爬到 22 rad/s，角度整圈环绕；20×14 木箱单放 |ω| = 0。
- 逐 tick 浮力探针：采样水面 `h` 在 102↔121 间乱跳（真水面 120），木条竖起时 `h` 贴着木条顶端，
  判 192/192 全淹没，v = −18 格/s（阻力限速）出水；横拍回水面时 arm = −9.1、ω = +9.8——力矩与 ω
  同号做正功。
- ASCII 地图（`crates/sand-core/src/body.rs` 的 `stamp_body` 排开路径）：木条周围是一座 15+ 格高的
  水丘贴着迎水面，尾流是空腔。排开的水以刚体**线速度**弹出，粒子落回迎水面随刚体走。

## 根因

1. `surface_line` 采紧邻 4 列、取中位数——正好被自溅水丘俘获，读数只会偏高，偏高是正反馈。
2. 阻力只阻线速度（`apply_drag`），角速度零耗散（Rapier 缺省 angular damping = 0），能量只能
   留在旋转里。
3. 淹没量整行计数：`a04ebd0` 说明里的"像素分数"并未落地。32 宽木条一行 = 200 格/s² 的力阶，
   平衡点在台阶立面上，浮体每 tick 在 ±1.7 格/s 间抖，永远过不了 1 格/s 睡眠阈值。

## 修

`crates/sand-core/src/body.rs`：`surface_line` 取最低者 + 每侧再加隔 3 格的远 2 列 + 先碰邻体的列
作废；`apply_buoyancy` 按像素连续世界中心与 `y ≥ h` 的竖向重叠分数计权，同一 `K_DRAG` 补角阻力
`−K·Σw|r|²·ω`（`physics.rs` 的 `apply_angular_drag`）。

## 验证

- 单测 16 绿（`surface_line_and_submerged_count` 改为"取最低者"，新增邻体挡列用例）。
- 行为测试 17 绿，新增 `plank_in_deep_pool_does_not_spin_up`（|ω| < 6、1500 tick 后 < 0.5、入睡）。
  实测木条 |ω| 峰 1.6、tick 500 入睡；三体同池 tick 2000 前全部入睡。
- `cargo test --workspace` 全绿（crate_yard golden 重录；六配置 2 万 tick SyncTest 325 s 零分叉）。
- bench `crate_yard` 5000 tick：1T 1.066 → 0.720 ms，8T 1.050 → 0.768 ms（浮体能睡了）。

## 教训

- "施力不唤醒 + 收阈值"只是让浮体**有资格**睡；力是位姿的阶梯函数时它永远到不了阈值。
- 任何由环境采样决定大小的力，先问：刚体自己会不会改这个采样？会的话，取对自扰动**单调不利**
  的那一侧（这里是最低水面）。
- commit 说明里写了没落地的东西（"像素分数"），下一次目检就被当成已知事实绕过去了。
